Project Overview

StaticShield is a proposed web-based prototype for the FYP titled Machine Learning-Based Static Malware Analysis.

Research focus

Static malware analysis

Files are analyzed through static characteristics without executing the malware. This supports safer and more efficient screening.

Dataset

EMBER

The model-development pipeline uses the publicly available EMBER dataset containing labeled malware and benign samples with static PE-related features.

Models

Random Forest + XGBoost

Both models are planned for development and comparison. The best-performing model will be selected for the prototype deployment.

Machine Learning Development Lifecycle

Proposed development methodology

1. Problem Definition

Define the malware-detection problem, objectives, requirements, and scope.

2. Data Collection

Obtain and inspect the EMBER dataset and its labels/features.

3. Data Preprocessing

Clean data, select static features, and prepare training/testing sets.

4. Model Development

Train Random Forest and LightGBM classifiers.

5. Model Evaluation

Compare accuracy, precision, recall, F1-score, ROC-AUC, and false positive rate.

6. Testing & Validation

Check functionality, integration, reliability, and generalization on unseen samples.

7. Deployment

Integrate the selected model into the web-based prototype for file classification.
