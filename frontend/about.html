Project Overview

StaticShield is a web-based prototype for detecting malware in Windows PE files through static analysis and machine learning.

Research focus

Static malware detection

The system examines file characteristics without executing the uploaded executable.

Dataset

EMBER 2018 v2

The models were developed using labelled PE samples and 2,381-dimensional static feature vectors.

Models

LightGBM & Random Forest

Both classifiers were trained and evaluated. Both models analyse each uploaded file independently using the same extracted feature vector.

Machine Learning Development Lifecycle

Development and evaluation workflow

1. Problem Definition

Define the malware-detection problem, objectives and scope.

2. Data Collection

Use the EMBER 2018 v2 dataset and its labelled samples.

3. Data Preprocessing

Prepare the static feature vectors and training/testing data.

4. Model Development

Train LightGBM and Random Forest classifiers.

5. Model Evaluation

Evaluate accuracy, precision, recall, F1-score, ROC-AUC and false positive rate.

6. Testing & Validation

Test feature extraction, model prediction and web application functionality.

7. Deployment

Integrate both classifiers into the local web-based prototype.
